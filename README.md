# TVim — текстовый редактор в духе vim на tvision-rs

Модальный редактор с привычными клавишами vim, окнами, меню и диалогами
Turbo Vision. Всё, что в vim настраивается в `.vimrc`, здесь меняется в
диалогах (и, по желанию, командой `:set`), а сохраняется в файл настроек.

## Сборка

Нужна библиотека [tvision-rs](https://github.com/cat386/tvision-rs) в соседнем каталоге:

```text
git clone https://github.com/cat386/tvision-rs
git clone https://github.com/cat386/tvim
cd tvim
cargo run --release -- [файлы...]
cargo test
```

Справка внутри редактора — `F1` или `:help [тема]`.

## Что умеет

**Режимы.** NORMAL, INSERT, REPLACE, VISUAL (символы `v`, строки `V`, блок
`Ctrl-V`/`Ctrl-Q`), командная строка `:` и поиск `/` `?` с пошаговой
подсветкой.

**Обычный режим.** Счётчики, регистры (`"a`, `"A`, `"0`, `"1`, `"_`, `"+`),
движения (`w b e ge W B E 0 ^ $ g_ gg G H M L f t F T ; , % { } * # n N`,
метки `ma 'a`), операторы `d c y > < gu gU g~` с движениями и текстовыми
объектами (`iw aw ip ap i( a" it`…), `x X D C s S J gJ r ~ p P`, `u`/`Ctrl-R`
(многоуровневая отмена), повтор `.`, макросы `qa … q @a @@`, `Ctrl-A`/`Ctrl-X`,
прокрутка `Ctrl-F/B/D/U/E/Y`, `zz zt zb`, `gf`, `ZZ ZQ`, окна `Ctrl-W`, `gt`.

**Вставка.** Автоотступ и «умный» отступ после `{ ( [ :`, мягкая табуляция,
`Ctrl-W Ctrl-U Ctrl-T Ctrl-D`, дополнение слов `Ctrl-N/Ctrl-P`, `Ctrl-R
регистр`, `Ctrl-O` — одна команда обычного режима, вставка в блок `I`/`A`.

**Команды `:`.** Диапазоны (`% . $ 'a '<,'> /обр/ +N`), `:w :wq :x :q :q! :wa
:qa :e :e! :enew :new :r :s :g :v :d :y :pu :m :t :j :> :< :normal :sort
:retab :set :setf :syntax :colorscheme :map/:nmap/:imap/:vmap :unmap :noh
:marks :registers :cd :pwd :!команда :[диап]!фильтр`. Несколько команд — через
`|`. Tab дополняет команды, параметры, языки и имена файлов; `↑ ↓` — история.

**Регулярные выражения vim.** `. * \+ \= \{n,m} \{-} [..] ^ $ \< \> \( \) \|
\d \s \w \c \C \v`; в замене `& \1..\9 \u \l \U \L \E \r`.

**Подсветка синтаксиса** (с учётом многострочных комментариев и строк):
Rust, C, C++, C#, Java, Kotlin, JavaScript, TypeScript, Go, Python, Ruby,
PHP, Lua, Shell, Batch, PowerShell, SQL, Pascal/Delphi, JSON, TOML, INI, YAML,
Markdown, HTML, XML, CSS, Makefile, Diff, CMake. Язык определяется по
расширению/имени файла (настраивается) и по строке `#!`.

**Файлы.** UTF-8 (и с BOM) и Windows-1251 распознаются сами и сохраняются
обратно в той же кодировке и с теми же концами строк (`:set ff=dos|unix`,
`:set fenc=cp1251`). Резервная копия `.bak` и удаление пробелов в конце строк
— по желанию.

## Настройки через диалоги

| Меню «Настройки» | Команда | Что настраивается |
|---|---|---|
| Параметры редактора (`F9`) | `:set`, `:options` | номера строк (и относительные), подсветка текущей строки, видимые табуляции, подсветка синтаксиса и найденного, парные скобки; табуляция, отступ, пробелы вместо табуляции, автоотступ, умный отступ; регистр при поиске, поиск по кругу; общий буфер обмена; резервные копии; поля прокрутки, граница `colorcolumn`, клавиша `<Leader>` |
| Цветовая схема | `:colorscheme` | 5 готовых схем (Borland, тёмная, светлая, матрица, пустыня) и цвет каждого из 27 элементов — с живым образцом |
| Типы файлов и подсветка | `:syntax` | какие расширения/имена каким языком подсвечивать, своя табуляция и `expandtab` для языка |
| Тип файла этого окна | `:setf` | язык подсветки текущего окна |
| Сопоставления клавиш | `:map` | свои сочетания для обычного, визуального режимов и вставки (`jk → <Esc>`, `<Leader>w → :w<CR>`) |
| Общие настройки | `:preferences` | тема Turbo Vision, язык интерфейса, мышь (стандартный диалог tvision-rs) |

Настройки хранятся в `tvim.settings.json` рядом с программой (поле `extra.tvim`);
другой путь — переменная окружения `TVISION_SETTINGS`.

## Устройство

| Модуль | Назначение |
|---|---|
| `keys.rs` | клавиши vim (`VKey`) и нотация `<C-x>`, `<Leader>` |
| `regex.rs` | регулярные выражения vim (поиск с возвратами) |
| `syntax.rs` | описания языков и раскраска строки с состоянием на её начале |
| `config.rs` | параметры, цветовые схемы, типы файлов, сопоставления; JSON |
| `buffer.rs` | текст (`Vec<Vec<char>>`) и группы отмены |
| `encoding.rs` | UTF-8 / CP1251, концы строк |
| `editor.rs` | представление `VimEditor`: режимы, вставка, командная строка, поиск, регистры, отрисовка |
| `normal.rs` | разбор команд обычного/визуального режима, движения, операторы, текстовые объекты |
| `ex.rs` | команды `:` |
| `window.rs` | окно с полосой прокрутки |
| `dialogs.rs` | диалоги настроек |
| `app.rs` | меню, строка состояния, окна, файл настроек |

Меню и строка состояния используют только F-клавиши и Alt — все сочетания с
Ctrl остаются редактору (как в vim).

Тесты: `tests/vim.rs` — сценарии vim (клавиши → текст), `tests/app.rs` —
приложение целиком на тестовом терминале (отрисовка, диалоги, выход).
